# Third-party materials

`LICENSE` applies to original project integration code and documentation only.
Downloaded upstream code, pretrained weights, reference data, and their derived
materials retain their own terms; this package does not relicense them.

The unmodified official validator is bundled under the organizer repository's
BSD-3-Clause license, reproduced in `third_party/amp-challenge-LICENSE`.
The official antibacterial reference is copied from the recorded organizer
revision; its provenance and SHA-256 are in `records/model_sources.json`.

Third-party model weights are not bundled. The runtime downloads them from the
sources in `DATA_AND_MODELS.md`. Historical project notes identified restrictive
or unclear terms for some components; those notes are not a fresh license audit.
Full permissive-release/co-authorship eligibility has not been established.
The package must not be described as having all third-party weights and data
cleared for redistribution.
